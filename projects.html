Projects

Here are some of the projects I've worked on.

MowBot

A simulation-based project focusing on developing an AI-powered lawn mower system. The system combines terrain classification and path planning. Made with 3 other students, we built this project within the last month of our intro to AI class.

PriceHunt

A simple full-stack Android application to help find deals on various items. Made with 4 other students, I was in charge of leading the team, and making arrangements while following a software development life cycle.

Walkie Talkie

A project I made with a partner was a simple "Walkie Talkie" application that is built mainly using Python's Socket API (TCP) and an external library called sounddevice. It allows for multiple clients to connect to a central server and communication between the different clients by holding a push-to-talk button on the GUI. This was for a networking class and helped with understanding networking further.

Overcooked

A simple and chaotic web application that generates random recipes. Made for a hackathon called ChaosHack 2024.
