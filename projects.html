Walkie Talkie

A project I made with a partner was a simple "Walkie Talkie" application that is built mainly using Python's Socket API (TCP) and an external library called sounddevice. It allows for multiple clients to connect to a central server and communication between the different clients by holding a push-to-talk button on the GUI. This was made for a final project in a networking class and helped with understanding networking even further.
